# Code of Conduct

This is a small, friendly teaching project. The expectations below apply to everyone who participates in this repository, in issues, in pull requests, and in any related discussion.


## Our standards

We want this to be a welcoming place to learn. Please:

- Be kind and respectful. Assume good intent.
- Be patient with people who are new to LLMs, LangChain, Streamlit, or Python in general.
- Give feedback on the work, not the person. "This code does X, which can cause Y" is great. Personal attacks are not.
- Keep discussions focused on the project.

We will not tolerate:

- Harassment, insults, or discriminatory language of any kind.
- Sharing other people's private information.
- Sustained disruption of conversations or reviews.
- Sexualized language or imagery.


## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, commit messages, and any communication identifiable as being about this repository.


## Enforcement

If you see behavior that breaks this Code of Conduct, please contact the maintainer privately through the GitHub profile at https://github.com/ANI-IN. Reports will be handled with discretion.

The maintainer may take any action they consider appropriate, up to and including blocking a contributor from the repository.
